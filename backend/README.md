# Карта «Лучшее лето в жизни» — OpenStreetMap + MySQL + премодерация

Версия механики с базой MySQL и обязательной премодерацией историй.

## Как теперь работает сценарий

1. Пользователь нажимает на точку карты.
2. Пишет историю до 300 символов.
3. История сохраняется в MySQL со статусом `pending`.
4. Пользователь получает сообщение:
   **«Спасибо! История отправлена на премодерацию. Как только мы проверим её на корректность, она появится на сайте. Следите за обновлениями.»**
5. История НЕ появляется на публичной карте сразу.
6. Модератор открывает `admin.php`, входит по паролю и нажимает **«Опубликовать»** или **«Отклонить»**.
7. На публичной карте отображаются только записи со статусом `approved`.

## Файлы

- `index.php` — публичная карта.
- `api.php` — получение опубликованных историй и приём новых историй.
- `admin.php` — закрытая страница премодерации.
- `db.php` — подключение к MySQL и автоматическое создание таблицы.
- `config.php` — настройки карты, MySQL и пароль модератора.
- `install.sql` — SQL для ручного создания таблицы через phpMyAdmin, если понадобится.

## 1. Создайте MySQL-базу

В панели хостинга создайте:

- базу данных;
- пользователя MySQL;
- выдайте пользователю права на эту базу.

Саму таблицу `stories` проект попытается создать автоматически при первом обращении.
Если ваш хостинг запрещает `CREATE TABLE` для пользователя приложения, импортируйте `install.sql` через phpMyAdmin.

## 2. Заполните `config.php`

Минимально нужно заменить эти значения:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'ИМЯ_БАЗЫ');
define('DB_USER', 'ПОЛЬЗОВАТЕЛЬ_БАЗЫ');
define('DB_PASS', 'ПАРОЛЬ_БАЗЫ');

define('ADMIN_PASSWORD', 'СВОЙ_СЛОЖНЫЙ_ПАРОЛЬ');
```

Если хостинг выдал другой адрес MySQL или порт, поменяйте также `DB_HOST` / `DB_PORT`.

## 3. Загрузите файлы на сервер

Откройте `index.php`.

Если подключение к БД работает, публичная карта загрузится. Пока нет одобренных записей, пинов на ней не будет.

## 4. Проверка премодерации

1. Поставьте точку на `index.php`.
2. Отправьте историю.
3. После отправки пин **не должен** появиться сразу.
4. Откройте:

```text
https://ВАШ-ДОМЕН/ПУТЬ/admin.php
```

5. Введите `ADMIN_PASSWORD` из `config.php`.
6. Нажмите **«Опубликовать»**.
7. Обновите `index.php` — история должна появиться на карте.

## Статусы записей

- `pending` — ожидает проверки;
- `approved` — опубликована на карте;
- `rejected` — отклонена и не показывается пользователям.

## Таблица MySQL

```sql
stories
- id
- lat
- lng
- comment
- status
- created_at
- reviewed_at
```

Текст хранится в `utf8mb4`, поэтому поддерживаются русский язык и emoji.

## Безопасность

- Публичный API никогда не отдаёт `pending` и `rejected` истории.
- Админка защищена отдельным паролем и PHP-сессией.
- Действия модерации защищены CSRF-токеном.
- SQL-запросы с пользовательскими данными используют prepared statements.
- Перед публичным запуском обязательно замените `ADMIN_PASSWORD` и пароль MySQL.
- Лучше запускать сайт по HTTPS.

Для MVP пароль модератора хранится в `config.php`. На продакшене лучше передавать `ADMIN_PASSWORD`, `DB_USER` и `DB_PASS` через переменные окружения хостинга.

## OpenStreetMap

API-ключ карты не требуется. По умолчанию используется:

```text
https://tile.openstreetmap.org/{z}/{x}/{y}.png
```

Атрибуция `© OpenStreetMap contributors` должна оставаться видимой.
Для крупной рекламной кампании лучше перейти на отдельного коммерческого провайдера OSM-тайлов, не меняя остальную механику проекта.
